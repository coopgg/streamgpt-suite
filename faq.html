Troubleshooting

Start with these in order:

  • Check the Streamer.bot action log. It shows exactly which sub-actions ran and what failed
  • Confirm your OpenAI API key is correct and your account has billing enabled
  • Check that C:\StreamGPT exists and contains config.py
  • If an action reports a compile error, open it in Streamer.bot and press Save and Compile

The setup guide includes a troubleshooting section with the most common issues and fixes. If you're still stuck, bring the Streamer.bot log to the Discord and someone can help.

  • Billing enabled? New API accounts need a payment method added at platform.openai.com/account/billing before the key works
  • Key copied correctly? Open C:\StreamGPT\config.py and confirm the key is there, with no extra spaces or missing characters
  • Monthly limit hit? Check your usage at platform.openai.com/usage
  • Key revoked? Old keys can be deactivated, so generate a new one at platform.openai.com/api-keys and update config.py

Usually one of three things:

  • The action for that command wasn't compiled: open it in Streamer.bot and press Save and Compile
  • The command is disabled in Streamer.bot, or uses a different prefix
  • That feature's actions were disabled or deleted after the import
