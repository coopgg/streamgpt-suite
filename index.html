Before you buy

StreamGPT Suite is a technical product. Make sure you have everything below before purchasing.

Windows PC

Required

Streamerbot is Windows-only. This suite does not work on Mac or Linux. You need to be running Windows 10 or 11.

Streamerbot

Free

The automation hub everything runs through. Free to download at streamerbot.github.io. You need to have it installed and connected to your Twitch account before setup.

Python 3

Free

The installer and all AI scripts run on Python. Free at python.org. You need to be comfortable opening a terminal and running a script. Nothing beyond that.

OpenAI Account + API Key

Ongoing cost

Required for all AI features. Create an account at platform.openai.com and add a payment method. The API key is entered during setup, and the suite handles everything else.

About OpenAI API costs

GPT-4o-mini is extremely affordable; most streamers spend $1 to $3 a month depending on how active their chat is. You're billed only for what you use, and you can set a monthly spend limit in your OpenAI account dashboard.

Comfort level: Beginner to Intermediate. If you've ever installed software, run a script, or followed a technical setup guide, you can do this. The installer handles the hard parts: you answer prompts, and it configures everything. A detailed setup guide is included.

Get set up in minutes

You need Streamerbot, Python 3, and an OpenAI API key.

1

Purchase and download

Get StreamGPT Suite on Ko-fi. Your download includes the installer and setup guide, so you have everything you need.

2

Run the installer

Open a terminal and run python StreamGPT_Suite_Setup_v0.9-beta.py. Answer the prompts: your API key, streamer name, currency name, emotes, and which systems to install.

3

Import into Streamerbot

Open Streamerbot → Import → select StreamGPT_Suite_Import.json. All 124 actions are created automatically.

4

Compile and go live

Open each Execute - #Code action and click Save and Compile. Type !balance in chat. If the bot responds, you're live.
