Before you buy

StreamGPT Suite is a technical product. Make sure you have everything below before purchasing.

Windows PC

Required

Streamer.bot is Windows-only. This suite does not work on Mac or Linux. You need to be running Windows 10 or 11.

Streamer.bot

Free

The automation hub everything runs inside. Free to download at streamerbot.github.io. Install it and connect it to your Twitch account before setup.

OpenAI account and API key

Ongoing cost

Required for the AI features. Create an account at platform.openai.com and add a payment method. You paste the API key into one settings file during setup.

About OpenAI API costs

StreamGPT Suite costs $15 once. The OpenAI API is separate: you pay OpenAI directly for usage. GPT-4o-mini is extremely affordable, and most streamers spend $1 to $3 a month depending on how active their chat is. You are billed only for what you use, you can set a monthly spend limit in your OpenAI account dashboard, and the suite caps itself at 30 AI requests a minute so a runaway loop can never run up a bill.

Comfort level: Beginner. If you have ever installed software and edited a text file, you can do this. There is no installer to run and no Python to set up. You copy a folder, add your OpenAI key and names to one settings file, and import one file into Streamer.bot. A detailed setup guide is included.

Get set up in minutes

You need Streamer.bot and an OpenAI API key.

1

Purchase and download

Get StreamGPT Suite on Ko-fi. The download includes the Streamer.bot import file, the StreamGPT folder with your settings file, and a setup guide.

2

Add your settings

Copy the StreamGPT folder to C:\StreamGPT. Open config.py in any text editor and fill in your OpenAI API key, your streamer and bot names, your currency name and your emotes.

3

Import into Streamer.bot

Open Streamer.bot, choose Import, and select StreamGPT_Suite_Import.json. All 113 actions and 94 commands are created for you. A few channel point actions need you to attach your own reward.

4

Go live

Type !balance in chat. If the bot answers, you are set. If an action reports a compile error in the Streamer.bot log, open it and press Save and Compile.
